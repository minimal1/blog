첫 CLI는 별도 설정 파일 없이 현재 디렉터리를 읽습니다. 패키지 정보와 빌드 스크립트를 확인해 가장 가능성 높은 명령을 제안합니다.

자동 감지는 편하지만 잘못된 추측이 위험합니다. 그래서 확실하지 않은 경우에는 실행하지 않고 감지한 내용을 먼저 보여줍니다.

```text
framework  Astro
build      pnpm build
output     dist/

Deploy with these settings? (y/N)
```

## 마법보다 복구 가능성

모든 프로젝트를 자동으로 맞히려고 하지 않았습니다. 실패했을 때 사용자가 무엇을 고쳐야 하는지 알 수 있는 편이 중요했습니다.

현재는 세 가지 정적 사이트 구성을 지원합니다. 베타 사용자의 실제 저장소에서 반복되는 패턴이 보일 때 다음 구성을 추가할 계획입니다.
